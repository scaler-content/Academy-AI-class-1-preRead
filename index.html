1. Welcome

Across the first three classes, you build a website summariser. Class 1 makes the first model call; Class 2 improves the instructions; Class 3 connects a real web page, model and interface.

What to focus on
Understand the mental model first; you do not need to memorise every detail before class.

2. The big idea: AI words are not interchangeable

AI is the broad category. Generative AI creates content. An LLM generates text by predicting likely next tokens. An AI agent uses a model with tools and the ability to choose steps toward a task. The key test is who decides what happens next.

3. What a model actually does

A model receives context and generates a continuation. Fluent text is not proof of truth. The prompt, history, supplied documents and answer all compete for space in the context window. Tokens affect both context limits and cost.

4. The model is the engine, not the product

A product also needs instructions, context, data access, an interface and error handling. Choose a model based on the task, latency, cost and reliability—not just its name or a benchmark.

5. The first API call

The system message guides behaviour; the user message supplies the task; the assistant message is the response. You will use Python to call a model. Keep your API key in a local `.env` file, never in source code or a public repository.

6. What can go wrong?

Models can invent details, misunderstand vague instructions, run out of context or vary their responses. Temperature changes sampling behaviour; lower temperature may improve consistency, but it does not guarantee accuracy.
